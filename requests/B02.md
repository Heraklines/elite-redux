### B02-7 Condition context for a stat-change condition (adapter)

- What: a `ConditionContext` (for example `"stat-change"`) and an adapter `asStatChangeCondition` in
  `vocabulary/evaluate/conditions.ts`, plus its case in `build-attr.ts` `adaptCondition` and in the L1 differential
  (`bindingCases`, `callClosure`).
- Formula: the engine closure type is `PokemonStatStageChangeCondition = (target, stats, stages) => boolean`. The adapter
  must build the frame `{ holder: target, stat: stats[0], stages, simulated: true }` and call the compiled library IF.
- Source: `PostStatStageChangeStatStageChangeAbAttr` constructor argument 0 and `canApply`
  (`this.condition(pokemon, stats, stages) && !selfTarget`).
- Needed by: PostStatStageChangeStatStageChangeAbAttr (6 attrs: Defiant 128, Competitive 172, Contempt 5312,
  Narcissist 5617, Lucha Libre 5686, Duality 5725). All six closures are `stages < 0`, which is the existing atom
  `stage.just-changed { direction: "lowered" }`; the moment the adapter exists the six bindings become
  `bindCondition(id, idx, { id: "stage.just-changed", direction: "lowered" }, "ctor:0")`.
- Status of the clause until then: `legacy-closure` (six `bindLegacyClosure` lines in `decl/B02/bindings.ts`).

### B02-1 `effect.stat-stage` range and `event.after-crit-taken` composable

- `effect.stat-stage` limits `stages` to -6..6. `PostReceiveCritStatStageChangeAbAttr` passes 12 for 8 of its 11 attrs
  ("maximise"), which is a valid input of `StatStageChangePhase` (it clamps at +6). Please allow -12..12 or add a
  "to the maximum" switch, otherwise a staff-built "Anger Point" cannot be written.
- `event.after-crit-taken` (dispatch key `PostReceiveCritStatStageChangeAbAttr`) is not `composable: true`, so a staff
  composition cannot be hung on it, and the harness has no `PARAM_BUILDERS` entry for it. The engine parameter object is
  the same `PostMoveInteractionAbAttrParams` as `event.after-hit`, dispatched only when `wasCritical`
  (`move-effect-phase.ts`, after `applyAbAttrs("PostDefendAbAttr", ...)`).
- Needed by: PostReceiveCritStatStageChangeAbAttr (11 attrs).
