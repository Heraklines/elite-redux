# Requests from batch B03 (chunk 1) to the librarian (B19)

Not code. Each entry: id, what it must do, the source line it comes from, and which classes and abilities wait for it.
Source lines are in `src/data/abilities/ab-attrs.ts` of the B03 branch unless another file is named.

## Conditions (IF atoms)

### `rng.chance` option `alwaysRoll` (boolean, default false)
- What: when true, the atom draws `holder.randBattleSeedInt(100) < pct` even at `pct >= 100`. Today the atom answers true
  at 100 without a draw, so a rebuilt rule draws one random number fewer than the original and shifts every later draw.
- Source: `PostAttackApplyBattlerTagAbAttr.gate` (`pokemon.randBattleSeedInt(100) < this.chance(...)`, `ab-attrs.ts`,
  the class near line 2327) always draws, even for a chance closure that answers 100.
- Waiting: `PostAttackApplyBattlerTagAbAttr` for Balloon Bomb (5318 attr 2), Hollow Ice Zone (5680 attr 0) and Wrestle
  Showman (5663 attr 1). Their gate bindings are legacy-closure.

### `move.has-flag-intrinsic` (new atom, param: move property, same options as `move.flag`)
- What: `move.hasFlag(MoveFlags[flag])`, the move's OWN flags. `move.flag` calls `doesFlagEffectApply`, which also asks
  the user's abilities that inject flags (`isMoveFlagInjector`: `MoveFlagInjectionAbAttr`, `RapierFlagInjectionAbAttr`),
  so the two answers differ for such holders. Label: "The move itself has the {flag} property". Requires: move.
- Source: the chance closures `(_u, _t, move) => move.hasFlag(32|128|256|134217728) ? N : 0` in
  `init-elite-redux-*` / `archetype-dispatcher.ts` (Frostmaw, Icicle Fist, Deep Cuts and Puncture, Sharp Talons).
- Waiting: `PostAttackApplyBattlerTagAbAttr` for Frostmaw (5395 attr 0, biting, 50), Icicle Fist (5718 attr 1,
  punching, 30), Deep Cuts (5438 attr 0, slicing, 50), Puncture (5942 attr 0, slicing, 50), Sharp Talons (5651 attr 0,
  kicking, 50).

### `move.has-flinch-effect` (new atom, no params)
- What: `move.hasAttr("FlinchAttr")`, "the move can make the target flinch by itself". Label: "The move can already make
  the target flinch". Requires: move.
- Waiting: `PostAttackApplyBattlerTagAbAttr` for Stench (1 attr 0) and Pungency (6085 attr 0).

### `move.hits-substitute` (new atom, no params)
- What: `move.hitsSubstitute(user, target)` ("the move would hit the target's Substitute instead of the target"). Label:
  "The move hits the target's Substitute". Requires: move, moveUser, other.
- Source: `Move.hitsSubstitute`, `src/data/moves/move.ts:572`.
- Waiting: Stench and Pungency (same attrs as above).

### `status.just-set` (new atom, param: status list)

- Source: `SynchronizeStatusAbAttr.gate`, `new Set([BURN, PARALYSIS, POISON, TOXIC]).has(effect)`.
- Waiting: `SynchronizeStatusAbAttr` (Synchronize, 28 attr 1).

### `mon.ability-replaceable` (new atom, param: who)

### `mon.in-ability-target-form` (new atom, param: who)

## Conditions (IF atoms)

### `mon.is-trapped` (new atom, param: who)
- What: `pokemon.getTag(TrappedTag) !== undefined`, an `instanceof` test, so it is true for EVERY trapping effect (Trapped,
  Ingrain, Octolock, No Retreat, and every binding move such as Bind and Wrap), not for one battle effect name.
  `tag.has` takes one `BattlerTagType` and cannot say this. Label: "{who} cannot leave the battle (it is trapped)".
  Requires: the chosen slot.
- Source: the closure `(opponent) => opponent.getTag(TrappedTag) !== undefined` of Grip Pincer and Venoblaze Pincers
  (`src/data/elite-redux/archetype-dispatcher.ts`, near line 5495); `Pokemon.getTag`, `src/field/pokemon.ts:6945`.
- Waiting: `IgnoreOpponentStatStagesAbAttr` slot `ctor:1` for Grip Pincer (5110 attr 1) and Venoblaze Pincers (5354 attr 3).
  Both bindings are legacy-closure.

## Binding facility

### Condition slot kind whose closure argument is the FOE (`ctx: "foe"`)
- What: today a constructor closure of the shape `(pokemon) => boolean` can only be declared with `ctx: "holder"`, whose
  compiled frame has that Pokemon as `holder`. `IgnoreOpponentStatStagesAbAttr.opponentCondition` is asked about the foe,
  so its atoms would read "who: holder" for the foe, which is wrong for staff. A slot kind `foe` should build the frame
  with `other` = the argument and `holder` unknown, so a staff condition reads "the foe is ...".
- Waiting: `IgnoreOpponentStatStagesAbAttr` slot `ctor:1` (declared with `ctx: "holder"` meanwhile; both users are legacy).

### Binding slot for attribute-level conditions (`AbAttr.addCondition`), slot name `extra`
- What: `AbAttr.addCondition(condition)` stores a yes/no closure on the instance (`extraCondition`) that the dispatcher asks
  through `getCondition()` BEFORE `canApply`. `recomposeAttr` copies it verbatim, but there is no slot to bind it to
  atoms, so it cannot be seen, swapped or removed by staff. Many users carry one and it is exactly the "IF" players
  want to change. Needed: a slot kind (any class), `bindCondition(abilityId, attrIndex, spec, "extra")`, an L1 predicate
  differential for it and an optional `extra` slot in `buildAttr`.
- Waiting (B03 chunk 2): `PostSummonAddBattlerTagAbAttr` for Protosynthesis (281), Quark Drive (282), Supreme Overlord
  (293), Madness Enhancement (5518 attr 2); `PostSummonMessageAbAttr` for Anticipation (107), Telepathy (140 attr 1),
  Aura Break (188 attr 2), Nihil Blaster (5679 attr 2), Zero to Hero (278 attr 4); `PostVictoryStatStageChangeAbAttr`
  (chunk 1) Battle Bond attr 4.
- Atoms those closures need (each calls the same engine predicate):
  - `field.terrain-in-list`: `!!arena.terrain?.terrainType && terrainTypes.includes(terrainType)` (Quark Drive;
    `field.terrain` takes one terrain).
  - `time.faints-this-battle {who}`: `(isPlayer ? arena.playerFaints : currentBattle.enemyFaints) > 0` (Supreme Overlord;
    `party.fainted-count` counts the party, not these battle counters).
  - `field.weather-fog`: `isFogWeather(arena.weather?.weatherType)` (Madness Enhancement; `field.weather` takes one
    weather and there are several fog weathers).
  - `field.weather-matches-list-with-terrain-exception`: Protosynthesis' closure (weather in a list, suppression, one ER
    Reap and Sow terrain exception) in `init-abilities.ts`; may stay legacy.
  - `foe.knows-dangerous-move`: any foe's move is an attack that is super effective against me or a one-hit knock-out
    (Anticipation, Telepathy), in `init-abilities.ts`.
  - `field.any-aura-ability`: `getField(true).some(p => abilityQuery(p, DARK_AURA_FIELD) || abilityQuery(p, FAIRY_AURA_FIELD))`
    (Aura Break, Nihil Blaster).
  - a once-per-battle memory for Zero to Hero, see the entry below.

## L2 harness (B20)

### Shadow ability id vs engine identity checks (Slow Start)
- What: `SlowStartTag.lapse` calls `abilityQueryById(pokemon, SLOW_START)` and ends the tag at once when the holder lacks
  that exact ability id. The L2 twin runs the rebuild under a shadow id, so the tag ends in turn 1 in the rebuild and
  `l2-twin.test.ts` fails for Slow Start although the attr is identical. Needed: let the shadow ability answer
  `hasAbility(originalId)` (an alias table on the shadow), or a per-class `l2InPlace: true` declaration flag that swaps the
  rebuilt attr into the real ability (what `test/tests/elite-redux/decomp/B03/chunk2.test.ts` does for Slow Start; note
  that `Ability.getAttrs` caches by array identity, so the cache has to be cleared after a swap).
- Waiting: `PostSummonAddBattlerTagAbAttr` (Slow Start 112).

### Studio carriers are invisible to the L1 fingerprint
- What: `attrFingerprint` finds the owner of `apply`, `canApply` and `getCondition` by walking PROTOTYPES, so an attr whose
  methods are assigned on the INSTANCE (a studio carrier, `runtime-components.ts` near line 606) is reported as a plain,
  identical use of its class. Malicious Empathy (20006 attr 8) is a carrier cloned from Air Lock's
  `PostSummonUnnamedMessageAbAttr`; a plain rebuild would silently drop its composed rule, and `DECOMP_L2_MODE=all` would
  twin it as a plain message attr. Needed: add `Object.hasOwn(attr, "apply" | "canApply" | "getCondition")` to the
  fingerprint (or skip carriers in `batchSites`), and a way for coverage to count carriers as "composition", not as users
  of the class.
- Waiting: `PostSummonUnnamedMessageAbAttr` (Malicious Empathy 20006 attr 8).
