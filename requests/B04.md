- Dispatch key: `CommanderAbAttr` (the class is dispatched by its own name, it does not extend PostSummonAbAttr).
- Call sites: `src/phases/post-summon-phase.ts:63` and `src/modifier/modifier.ts:2064`, both
  `for (const p of pokemon.getAlliesGenerator()) applyAbAttrs("CommanderAbAttr", { pokemon: p })`, so the holder is the
  ALLY of whoever entered or was revived.
- Remove `CommanderAbAttr` from `UNEXPOSED_DISPATCH_KEYS` in `vocabulary/dispatch-keys.ts` once the WHEN claims it.
- L2: needs a doubles scenario with a Dondozo ally (template `doubles-ally` uses Shuckle; a Dondozo variant is needed) or a
  written static reason.
- Needed by: CommanderAbAttr (Commander). The finished declaration is parked at
  `src/data/elite-redux/ability-studio/decl/B04/CommanderAbAttr.decl.pending.ts`; rename it to `CommanderAbAttr.decl.ts`
  after this WHEN exists (and set `when` to the final id).

## 2. Effects (DO)

All of these are currently declared as `effect.package` in the B04 declarations. Each should call the SAME engine function the class calls.

- `effect.revert-weather-forms`: "Return weather-based forms to normal". Formula: `arena.triggerWeatherBasedFormChangesToNormal()`
  (`src/field/arena.ts:574`; every Castform with Forecast and Cherrim with Flower Gift on the field, both sides, gets
  `SpeciesFormChangeRevertWeatherFormTrigger`). Skips when simulated. Needed by: PostSummonWeatherSuppressedFormChangeAbAttr
  (ab-attrs.ts:3496). The existing `effect.return-base-form` only changes the holder, so it is not the same.
- `effect.clear-weather`: "Clear the weather". Formula: `globalScene.arena.trySetWeather(WeatherType.NONE)` (it passes the
  immutable-weather guard, so primal weather ends too). Skips when simulated. Needed by: PostSummonClearWeatherAbAttr
  (ab-attrs.ts:3520, `apply`) and PreLeaveFieldClearWeatherAbAttr (ab-attrs.ts:3694). `effect.set-weather` with NONE goes
  through the V1 set-weather path, which is not proven to take this route.
- `effect.match-weather-form`: "Change to the form that fits the weather". Formula:
  `globalScene.triggerPokemonFormChange(pokemon, SpeciesFormChangeWeatherTrigger)` (no form key: the species' form-change
  table decides). Skips when simulated. Needed by: PostSummonFormChangeByWeatherAbAttr (ab-attrs.ts:3537). `effect.change-form`
  needs a named key, so it does not fit.
- `effect.change-form-by-ability` (or let `effect.change-form` take "no key"): "Change form (the species' own ability form change)".
  Formula: `globalScene.triggerPokemonFormChange(pokemon, SpeciesFormChangeAbilityTrigger, false)`. Skips when simulated.
  Needed by: PreSwitchOutFormChangeAbAttr (ab-attrs.ts:3662, Zero to Hero).
- `effect.cure-status` with status ANY: make it do exactly what PreSwitchOutResetStatusAbAttr does (ab-attrs.ts:3623):
  `pokemon.resetStatus(); clearErAilments(pokemon); pokemon.updateInfo();` (it must also clear the Elite Redux ailment tags
  Bleed, Frostbite and Fear). Today the V1 cure-status effect is only the nearest description. Needed by: PreSwitchOutResetStatusAbAttr.
- `effect.heal-percent`: make it use `toDmgValue(maxHp * pct / 100)` (floor, minimum 1) and call `pokemon.updateInfo()`
  like PreSwitchOutHealAbAttr (ab-attrs.ts:3643, `toDmgValue(pokemon.getMaxHp() * 0.33)`). Note the class' 33 is not 100/3.
  Needed by: PreSwitchOutHealAbAttr.

## 3. Condition atoms (IF)

- `mon.fainted{who}`: "{who} has fainted". Formula `pokemon.isFainted()` (`src/field/pokemon.ts` isFainted). Needed to express
  Zero to Hero's closure (`pokemon.isFainted() ? pokemon.formIndex : 1`). Also useful for any "not while fainted" rule.
- `mon.form-index{who, cmp, index}`: "{who} is in form number {index}". Formula `pokemon.formIndex <cmp> index`
  (`src/field/pokemon.ts` formIndex). Needed by: PreSwitchOutFormChangeAbAttr, whose gate is
  `formFunc(pokemon) !== pokemon.formIndex`, which for its only user equals `all[not mon.fainted{holder}, not mon.form-index{holder, eq, 1}]`.
  (`mon.in-form` takes a form KEY and cannot say form 1 without knowing the key; Palafin's key lives in er-newcomer-species.ts.)

## 4. Guards

- `another-holder-keeps-weather` (non-removable): "Does not end the weather while another Pokemon on the field still keeps it alive".
  Formula (ab-attrs.ts:3709-3716, clause 2 of `canApply`, after the weather-matches clause):
  `!globalScene.getField(true).some(p => p !== pokemon && p.getAbilityAttrs("PreLeaveFieldClearWeatherAbAttr").some(attr => attr.weatherType === this.weatherType))`.
  Requires: holder. Takes the class' own `weather` setting. Currently written as a feasibility line in
  PreLeaveFieldClearWeatherAbAttr; it moves to `guards` once the id exists, with no behaviour change.
