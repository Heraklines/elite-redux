## R-B07-1  A condition context for `(pokemon, move)`, two slots for `calc.ability-bypass`, and an effect "ignore the target's ability"

Blocks MoveAbilityBypassAbAttr (6 closures) and SuperEffectiveMoveAbilityBypassAbAttr (3 closures and 3 gates). Today all nine
closures and the three gates are `bindLegacyClosure` lines with the exact formula in their reason.

- **Context** `ConditionContext = "mover"` in `define-decl.ts` and `build-attr.ts` (`adaptCondition`): the engine signature
  `(pokemon, move) => boolean`, which fits none of "attack" (user, target, move), "defend" (target, user, move) or "holder"
  (pokemon). Adapter: `(pokemon, move) => condition({ holder: pokemon, move, moveUser: pokemon, simulated: true })`.
  Source: the constructor of `MoveAbilityBypassAbAttr` (ab-attrs.ts, `moveIgnoreFunc: (pokemon: Pokemon, move: Move) => boolean`,
  default `() => true`).
- **WHEN `calc.ability-bypass`** (dispatch key `MoveAbilityBypassAbAttr`): today it provides `holder` and `move`. It must also
  provide `other` (the defender, which `Move.doesFlagEffectApply` threads through as `target`, and which is `undefined` on
  target-less paths such as the ally accuracy line) and `moveUser`, and `WHEN_MOVE_USER["calc.ability-bypass"]` must be `"holder"`
  (the holder IS the move user). Without that the atoms `move.type`, `move.category` and `move.effectiveness` cannot be read
  there. Because `other` is optional, an atom that needs it must fail closed when it is absent (the class does: `target != null && ...`).
- **Bindings that become possible** (each is a one-line replacement of the legacy line in `decl/B07/bindings.ts`):
  - `() => true` (Mold Breaker 104/1, Turboblaze 163/1, Teravolt 164/1, Blind Rage 5397/3): an empty ALL group;
  - `move.category === STATUS` (Mycelium Might 298/2): `{ id: "move.category", category: "STATUS" }`;
  - `pokemon.getMoveType(move) === ROCK` (Stonecutter 5582/2): `{ id: "move.type", type: "ROCK", effective: true }`;
  - the gate `target != null && target.getMoveEffectiveness(pokemon, move) > 1` of Deadly Precision 5495/1, Flawless Precision 5622/1
    and Mach 3 5635/1: `{ id: "move.effectiveness", cmp: ">", n: 1 }` on slot `gate` (the L1 differential must also try "no foe").
- **Effect** `effect.ignore-target-abilities`, label "Ignore the target's ability" (a calc effect on `calc.ability-bypass`, `modifies`
  `cancelled`, `requires: []`, no params). Formula: `cancelled.value = true` (`MoveAbilityBypassAbAttr.apply`). `effect.negate` has the same
  mechanics but reads "Block it", which would mislead staff here, so it is not used. Both classes declare `effect.package` until it exists.
- Synonyms to carry: mold breaker, ignore abilities, bypass ability, teravolt, turboblaze, get past levitate.
