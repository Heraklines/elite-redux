# Requests from batch B10 to the librarian (B19) and the harness owner (B20)

These are requests, not code. Ids are `R-B10-nn`. Chunk 1 of 5 (the eight classes of `archetypes/nullify-first-n-hits.ts`,
`offensive-type-chart-override.ts`, `on-crit-stat-boost-lowest.ts`, `on-faint-effect.ts`, `on-opponent-stat-raise.ts` and
`on-opponent-switch-out.ts`). Later chunks append their own sections below.

## Chunk 1

### Memory and damage (NullifyFirstNHitsAbAttr: Cheating Death, Gallantry)

- **R-B10-01 `time.hits-taken-this-battle { cmp, n }` (group Time and memory).** True while the holder has been hit fewer than `n`
  times in the current battle, counting only hits that really did damage. The class keeps a `WeakMap<Pokemon, { battle, used }>`
  refreshed when `globalScene.currentBattle` changes; the atom must read the same counter (an exported accessor), so the class and
  the library form share one memory. Needs the `holder` slot.
- **R-B10-02 effect `effect.nullify-damage` (calc, modifies `damage`).** Sets the damage taken to 0 and marks it nullified
  (`markDamageNullified(damage)` from `#data/damage-nullification`) so later steps know the hit was cancelled on purpose, not a
  zero-damage move. It must not use up a charge when the call is simulated. Label: "Cancel the damage of the hit".

### Types (OffensiveTypeChartOverrideAbAttr, IgnoreResistancesAbAttr)

- **R-B10-03 WHEN `calc.my-type-chart-override` (done by this batch).** B10 added it to `when-registry.ts`, with the class name as its
  dispatch key, a template mapping in `scenarios.ts` and an entry in `decomp-l2-reach.json`, because no existing moment fits a
  class that the engine finds by name inside `Pokemon.getAttackTypeEffectiveness`. B08 added `calc.my-attack-matchup` for the same
  kind of class. The librarian should decide whether both are one moment ("While the game calculates how well my attack matches the
  target's types") and merge the ids; the declarations only name the id.
- **R-B10-15 effect `effect.change-type-matchup { attackType, defenderType, multiplier }`.** Replaces only the matched defender
  type's part of the matchup (including recomputing the product of the other types when the natural matchup is an immunity). This
  is what lets `OffensiveTypeChartOverrideAbAttr` stop being one piece. Until then its rule list is one text param.
- **R-B10-16 effect `effect.raise-resisted-hits-to-neutral`.** Any overall matchup above 0 and below 1 becomes 1, immunities and
  weaknesses stay (`IgnoreResistancesAbAttr`, Normalize). Today it is a presence flag read by name.

### Critical hits and stat boosts (OnCritStatBoostLowestAbAttr: Home Run)

- **R-B10-04 condition `hit.was-critical { who }` (group Move).** The target's first received hit this turn was a critical hit:
  `opponent.turnData.attacksReceived[0]?.critical === true`, false when there is no target. A cleaner atom would read the holder's own
  hit from the frame instead (the class reads the first hit the target took, which in doubles may be an ally's; see the notes of the
  declaration).
- **R-B10-05 condition `time.once-per-turn-shared { key }`.** The class's memory is a Symbol property on the Pokemon object holding the
  battle's turn number (`OnCritStatBoostLowest.lastTurn`). The library's `time.once-per` with scope `turn` uses its own store, so a
  library rebuild would not share the class's memory. Needs an exported accessor for both to read.
- **R-B10-06 effect `effect.raise-lowest-stats { count, stages }`.** Ranks the five stats Attack, Defense, Sp. Atk, Sp. Def, Speed by the
  holder's current stage (stable order, ties keep that order) and queues one self `StatStageChangePhase` per stat for the first
  `count`. Label: "Raise my lowest stats".

### When I faint (OnFaintEffectAbAttr: Haunted Spirit, Vengeful Spirit, Guilt Trip, Ill Will)

The library trigger `event.faint` exists and is composable, but the effects below need "the Pokemon that knocked me out" as a target.

- **R-B10-07 target `attacker` for `effect.stat-stage`.** Needs the target choices "the Pokemon that knocked me out" and "its allies"
  (Guilt Trip lowers the attacker's Attack and Sp. Atk by 2 and its living allies' by 1). Frame slot `other` is the attacker for
  `event.faint` (see `WHEN_MOVE_USER`).
- **R-B10-08 effect `effect.hurt-percent { target, percent }`.** Damage of a share of the target's max HP as indirect damage
  (`damageAndUpdate(toDmgValue(max * fraction), { result: HitResult.INDIRECT })`, `turnData.damageTaken += damage`), skipped for a
  Pokemon that blocks indirect damage. Feasibility: needs a known attacker and move.
- **R-B10-09 target `attacker` for `effect.apply-tag` with a list of types to skip.** Haunted Spirit and Vengeful Spirit curse the
  attacker unless it is a Ghost type. Must pass `holder.id` as the tag's source.
- **R-B10-10 effect `effect.drain-pp-of-move`.** Sets `ppUsed` of the move that knocked me out, in the attacker's moveset, to its full
  PP, then the move-used event and the "PP was reduced" message (Ill Will). Feasibility: a damaging move, a living attacker, the move in
  its moveset with PP left.

### Reacting to a foe (OnOpponentStatRaise*, OnOpponentSwitchOut)

- **R-B10-11 effect `effect.copy-foe-stat-boost`.** Raises my own copy of the stat and stages the foe just gained, as a change that
  cannot be copied again (`StatStageChangePhase(…, canBeCopied = false)`). The trigger `event.foe-raised-stat` already provides the stat
  and stages. (`OnOpponentStatRaiseAbAttr`, Egoist.)
- **R-B10-12 slot `other` for `event.foe-raised-stat`.** The trigger does not tell which foe raised its stat, so the library's
  "Use a move" effect (needs `other`) cannot express Retribution Blow. Today the class aims at the first living foe, not the raiser;
  if the librarian provides `other`, the owner should decide whether to keep that behaviour (it is recorded in the declaration notes).
- **R-B10-13 WHEN `event.foe-switches-out` (done by this batch).** Added to `when-registry.ts` with the class name as dispatch key and
  the slots holder and other (the leaving foe). `scenarios.ts` maps it to `holder-switches-out` and `decomp-l2-reach.json` lists it
  as unreached (the switch phase finds the class by name on the foe's side).
- **R-B10-14 `effect.scripted-move` parity.** The class aims a free INDIRECT move at the leaving foe. The library effect additionally
  refuses when the holder has fainted and needs a frame with `other`; the by-name scan builds no frame. Either the scan should build
  one or the effect should drop the holder check for this trigger, then `OnOpponentSwitchOutAbAttr` can use the library effect.
- **R-B10-17 harness.** `scenarios.ts` template `foe-raises-stat` now uses a Level 100 Shuckle as the enemy (it was a Level 30
  Magikarp): a holder that answers the raise with a strong move (a 150 power Hyper Beam) otherwise ended the battle and the twin
  never reached the next turn. B20 may prefer a template option instead of changing the shared one.

### Chunk 1 fix round (structured settings and gates; ids R-B10-c1-nn so they cannot clash with later chunks)

- **R-B10-c1-01 effect `effect.hurt-percent { target, percent }`.** Same as R-B10-08; needed by the "hurt the Pokemon that knocked me out" payload of OnFaintEffect.
- **R-B10-c1-02 effect `effect.apply-tag` made implemented, with a skip-types list.** The decl names it for the lasting-effect payload (Haunted Spirit, Vengeful Spirit); it must pass the fainting Pokemon's id as the source of the tag and skip attackers of listed types (R-B10-09).
- **R-B10-c1-03 effect `effect.arena-tag` implemented, with a layers count** for the hazard payload (R-B10-08 family).
- **R-B10-c1-04 effect `effect.drain-pp-of-move`.** Same as R-B10-10 (Ill Will, Cursed Spirit).
- **R-B10-c1-05 condition `mon.is-standing { who }` (group Pokemon).** True while the named Pokemon has not fainted (`!pokemon.isFainted()`); false when there is no such Pokemon. Needed so the gate of every OnFaintEffect user (the Pokemon that knocked me out is still standing) is a library atom instead of a legacy binding. With it, Haunted Spirit and Vengeful Spirit become `all[ is-standing(other), not has-type(other, Ghost) ]`, Guilt Trip `is-standing(other)`, Ill Will and Cursed Spirit `all[ is-standing(other), move.damaging ]`. The "move is in the attacker's moveset with PP left" clause stays the class's residual.
- **R-B10-c1-06 harness / librarian: a frame for `calc.my-type-chart-override`.** The engine scan calls `fire(moveType, defenderTypes, multi)` with a type and a type list; a library gate of `move.type` and `mon.has-type` needs a frame with a move and the target. Either the scan builds one or the effect R-B10-15 carries both conditions. Until then the two conditions are written as a branch of the declaration only.
- **R-B10-c1-07 foundation note.** B10 added one optional field `assembleCtorArg` to `ClassDecl` and 9 lines to `build-attr.ts` (not a library file, but not a batch file either): a constructor argument that is ONE structured object (rule list, one of seven payloads, an options object with an optional key) is built from the settings by a hand-written function instead of by a text sentence. The merge captain should keep it; B19 may prefer to move it to the foundation docs.

## Chunk 2 (`once-per-entry-contact-reduction.ts`, `one-shot-type-boost-then-lose-type.ts`, `outgoing-stat-drop-multiplier.ts`, `party-count-multi-hit.ts`, `passive-recovery.ts`, `persistent-field-aura.ts`, `poisoned-foe-purge.ts`)

Ids continue from chunk 1 (R-B10-15 to R-B10-17 above are chunk 1's).

### Memory shared with the class (OncePerEntryContactDamageReductionAbAttr: Chuckster; OneShotTypeBoost*: Power Outage)

- **R-B10-18 condition `time.once-per-entry-shared { key }` (group Time and memory).** True while the holder's once-per-entry charge is
  unspent, and the matching write when the effect runs. The class keeps the charge in `pokemon.summonData.chuckusterReductionUsed`
  (cleared at every send-out); the library's `time.once-per` with scope `entry` uses its own `battleData` store, so a library rebuild
  would not share the class's memory. The atom must read and write that field (an exported accessor). With it Chuckster becomes
  "once per entry, IF the move makes contact, multiply damage taken by 0.5" with no class guard.
- **R-B10-19 condition `time.spent-flag-shared { key }`.** True while a named one-time flag on the Pokemon is not set. Power Outage's two
  classes share the flag `OneShotTypeBoost.used` (a module-private Symbol written by the lose-a-type half). The atom needs an exported
  accessor for both halves.
- **R-B10-20 effect `effect.lose-type { type }` (event).** Removes one type from the holder (`summonData.types` = the other types; if that
  would leave none, the types stay), then refreshes the info box. Label: "Lose a type". Must do nothing when simulated, and also set the
  shared flag of R-B10-19 when used as the second half of Power Outage.

### Stat drops and hit counts (OutgoingStatDropMultiplierAbAttr: Subdue; PartyCountMultiHitAbAttr: Minion Control)

- **R-B10-21 condition `move.lowers-target-stats` and effect `effect.repeat-stat-drops { factor }`.** The condition is "the move I used has a
  stat-lowering change aimed at its target (not at the user)": `move.getAttrs("StatStageChangeAttr").some(a => a.stages < 0 &&
  !a.selfTarget)`. The effect queues, for each such drop, one extra `StatStageChangePhase` on the target of `floor(stages * (factor - 1))`
  stages (negative, so it rounds away from zero), only when the target is alive and the call is not simulated. Needs `move` and `other`.
- **R-B10-22 effect `effect.hit-per-healthy-ally { maxHits }` (calc, modifies `hitCount`).** `hitCount = min(hitCount + healthy, maxHits)`,
  where healthy counts the OTHER members of the holder's side party that are not fainted and have no status. Feasibility stays the
  parent's `move.canBeMultiStrikeEnhanced(holder, true, target)`. The planned `effect.hit-n-times` is a fixed count and cannot do this;
  the existing `party.count` atom could gate it.

### End-of-turn healing (PassiveRecoveryAbAttr: 17 attrs of 16 abilities)

- **R-B10-23 condition `status.asleep-or-comatose { who }`.** True when the Pokemon's status is SLEEP or `isComatoseLike(pokemon)` (an
  ability with the Comatose sleep rule, or an active Honk Shoo). Sweet Dreams (5071) and Peaceful Slumber (5220, attr 0) stay
  `legacy-closure` until it exists: a plain `status.has SLEEP` gives a different answer for a Comatose holder. Needs `holder`.

### Stat boosts and the poison purge (PoisonedFoePurgeAbAttr: Hemolysis; PersistentFieldAuraAbAttr: Fire Aspect, Polarity, Rat King)

- **R-B10-24 effect `effect.clear-stat-boosts { target }` (event).** Sets every positive battle-stat stage of the target to 0
  (`setStatStage(stat, 0)` for Attack, Defense, Sp. Atk, Sp. Def, Speed, Accuracy and Evasion, lowered stages stay) with no message. Hemolysis then adds the
  healing block as the existing `effect.apply-tag` (HEAL_BLOCK, only when the target does not have it): the two could be two blocks
  once this one exists.
- **R-B10-25 condition `mon.base-stat-total { who, cmp, n }` (group Pokemon).** `species.baseStats` summed, compared with `n`. Rat King's
  filter is "the ally's base stat total is below 400". Needs `other` (the Pokemon whose stat is read) for `calc.ally-stat-aura`.
- **R-B10-26 harness (B20): a condition slot under an options key.** `DeclCondition.slot` is `ctor:N` or `gate`; `PersistentFieldAuraAbAttr`
  keeps its closure under the key `predicate` of its ONE options object. Without a slot form such as `ctor:0.predicate` the filter
  cannot be bound as a library IF, so B10 carries it as the text param `allies` (a codec that builds the closure for "everyone on my
  side" and "base stat total below N" and reads a live closure back by asking it about stand-in allies). With R-B10-25 and this
  slot form the param can go.
- **R-B10-27 WHEN `calc.ally-stat-aura` (done by this batch).** Added to `when-registry.ts` with the class name as dispatch key (provides
  holder, other, stat), a template mapping in `scenarios.ts` and an entry in `decomp-l2-reach.json`, because the class is found by name
  inside `Pokemon.getStat` (`PersistentFieldAuraAbAttr.applyAuras`) and no existing moment fits. B08 and B09 may have added a similar
  moment for their by-name classes; the librarian decides whether they are one.
