## Chunk 2

Ids are `R-B11-C2-NN` so they never collide with the other chunks of B11.

HEADS-UP for the merge captain: two classes of this chunk are PARKED, not registered, because the trigger they need does not exist in the library (R-B11-C2-08 for PreemptivePriorityCounterAbAttr, R-B11-C2-13 for RecoilDamageMultiplierAbAttr) and chunk agents may not add one. A declaration that names an unknown trigger makes the catalog generator throw for the whole game, so the two finished declarations are kept as `requests/parked-decls-b11/<ClassName>.decl.ts.txt`. Once the librarian has added the two triggers: move each file to `src/data/elite-redux/ability-studio/decl/B11/<ClassName>.decl.ts`, set `when` to the real id (the files use `event.turn-start` and `calc.recoil-taken`), regenerate the catalog, add a scenario template or an L2 static reason for each trigger (both are by-name scans, never dispatched), and run `test/tests/elite-redux/decomp/B11/chunk2.test.ts`, whose rebuild half switches on by itself. Until then L0 for the whole batch (strict) reports these two classes as missing a declaration. Everything else of the chunk is green.
