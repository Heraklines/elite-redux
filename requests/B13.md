# Requests from batch B13 (chunk 1 of 6) to the librarian (B19) and the harness owner (B20)

Not code. One entry per request: id, what it must do, the source line, and which class needs it. Chunk 1 owns these
classes (all in `src/data/elite-redux/abilities/newcomer-signature-mechanics.ts`): FinalSeasonEntryAbAttr,
FinalSeasonFogAbAttr, FinalSeasonPowerAbAttr, FoulHarvestAbAttr, PorousResetAbAttr, PorousSoundReductionAbAttr,
PorousChargeAbAttr, PorousPowerAbAttr. Users: Final Season (5972), Foul Harvest (5973), Porous (5974), one each.

Every request below is the reason a clause is a `legacy-closure` binding (or sits in the class's `guards` / `residual`)
today. When the atom exists, the owning agent replaces the binding by the real spec and moves the clause into the gate.

## For the harness owner (B20)

### R-B13-33  L2 scenario where the FOE tries to leave, added by this chunk  (RingGeneralTrapAbAttr, trigger `calc.trap-check`)

- The template mapped to `calc.trap-check` was `holder-switches-out`, which makes the HOLDER switch out. A trapping ability (Ring

### R-B13-40  `effect.echo-move`  (SpiritPunchAbAttr.apply; EncoreSetAbAttr, chunk 5, is a close relative)

- Label: "Repeat the move I just used as an extra hit at {percent}% power". Params: `percent` (1-200, default 30), `bonusPercent` and
  `bonusType` (50, Ghost), `type` (the echo's type, default Ghost). Requires `other` and `move`. Formula

- Synonyms: "echo", "second hit", "repeat my attack", "double strike".
