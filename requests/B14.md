### Class edits that need the lead's approval (not made, not library files)

The brief allows only the Tier B `gate/residual` split inside a class. These classes hide numbers and types that staff
should be able to set; each would need a constructor argument with a default equal to today's value (so `new X()` and
every `builder.attr(X)` stay byte-identical). Until they are approved the declarations have zero params, each with a
written reason.

| Class | Fixed values that should become params |
| --- | --- |
| PhotovoltaicTypeAbAttr | the added type (Electric) |
| PropheticAbAttr | the list of moves (Future Sight, Doom Desire) and the delay (3 turns) |
| PerpetualMotionPowerAbAttr | the step (0.1 per hit) and the marker key `perpetual-motion` |
| PerpetualMotionProgressAbAttr | the marker key `perpetual-motion` |
| BitterDrillAbAttr | the field effect (Drill Bits), its side and its duration; the flag (drill) |
| SouthernCrossPunchAbAttr | the flag (punching) |
