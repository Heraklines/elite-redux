### R-B15-6 condition "The move has the {flag} property as printed" (group Move), for Crosscut (both attrs) and Draconic Voodoo

Formula: `move.hasFlag(MoveFlags[flag])` on the move's own printed flags, NOT `Move.doesFlagEffectApply`. The existing `move.flag` calls `doesFlagEffectApply` (src/data/moves/move.ts:994),
which also answers true for flags that an ability injects (Rapier, Taekkyeon and the other flag injectors) and strips contact for several abilities. Crosscut (src/data/elite-redux/abilities/crosscut.ts,
`isCrosscutTypedMove`: `move.category !== STATUS && (hasFlag(SLICING_MOVE) || hasFlag(PULSE_MOVE))`) and the Draconic Voodoo hit seam (`move.hasFlag(BITING_MOVE)`) use the printed flag, so the existing atom is a different predicate.
Requires `move`. With it, the two Crosscut gates become `all[ move.damaging, any[ printed SLICING, printed PULSE ] ]` (plus `not move.multi-hit` for the second strike); today both gates are `bindLegacyClosure`.
Used by Crosscut second strike (5908 attr 0), Crosscut power rider (5908 attr 1) and Draconic Voodoo (5930).

### R-B15-7 scope for `time.once-per` that shares a memory the class owns (group Time), for Dandelion Burst

Dandelion Burst (src/data/elite-redux/abilities/dandelion-burst.ts) remembers "used this wave" in its own module WeakMap (holder -> wave index): `DANDELION_BURST_USED.get(pokemon) === (currentBattle?.waveIndex ?? 0)` blocks the trigger, and

move the class to the shared Set and to update the AI reader to match. Today the check lives in the class `guards()` and is listed as feasibility. Used by Dandelion Burst (5907).
