### Class edits made in this chunk (all behaviour-neutral; the defaults equal the old literals)

These classes now take constructor arguments whose defaults equal the old hardcoded values, so `new X()` and every `builder.attr(X)` stay identical, and the
declarations expose them as params. Every class that was file-local is now `export`ed so its declaration can import it.

| Class | Change |
| --- | --- |
| ErBadDreamsAbAttr | `damagePercent` (default 25, replaces the literal `/ 4`; `m * 25 / 100` equals `m / 4` for every whole max HP) |
| BallasterAbAttr | `retaliationMove` (Steam Eruption), `retaliationPower` (80), `immediateTypes` (Fire, Water); Tier B split `canApply = guards && gate` in the original clause order |
| ConfectiousAttackAbAttr | Tier B split `canApply = guards && gate`; the inherited attack condition is `guards` clause 1 |
| StellarizePowerAbAttr | constructor `(condition, powerMultiplier)` with the old closure and 1.5 as defaults; Tier B split, the inherited condition is `guards` clause 1 and "I am Stellar type" is the gate |
| StellarizeTypeAbAttr | constructor `(newType, condition)` with Stellar and the Normal-move closure as defaults |
