## Disagreements with LIBRARY-DECISIONS.md

1. LD §5 Rejected lists `time.armed`, `effect.reset-memory` and `effect.set-marker` as "single-mechanic memory in a private
   WeakMap or module field". For B16 that is wrong: the memory is the public `erAbilityProvenance` array on battle/summon data
   (`src/data/pokemon/pokemon-data.ts:322,533,686`), which LD's own `time.marker-set` already reads. So `time.armed` (R-B16-3)
   is covered (Implemented via `time.marker-set`), and the writers are shared by several classes: Ballaster
   (`fakemon-pitch-mechanics.ts:326,328`), BallasterReset (`:273`), Eulogy (`:859`), OracleEntry (`:892-896`). Set/clear
   marker effects are Justified-unbuilt, not Rejected.
2. LD §5 "One-off effects of a single named ability (... B16 ...)" sweeps B16 whole. R-B16-13 serves 10 abilities (Drizzle,
   Drought, Sand Stream, Snow Warning, Orichalcum Pulse, Seaborne, Sand Bender, Supercell, Sundae, Solar Panel) and R-B16-19
   serves 5 (Psychic/Misty/Grassy Surge, Hadron Engine, Psychic Supremacy); neither is single-ability.
3. LD §5 Aliases names `hit.dealt-damage` among the `hitResult` aliases of R-B16-17 (c4); LD §1 implements `hit.dealt-damage`
   as `damage > 0`. R-B16-17 (c4) explicitly asks the result-only form: map it to `hit.landed-damage` / `hit-connected`, not
   `hit.dealt-damage`.
